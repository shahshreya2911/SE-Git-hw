# SE-Git-hw

## Overview

This repository was created for CINS 5318 Software Engineering Assignment #1.
The purpose of this assignment is to practice using Git and GitHub for version
control, branching, collaboration, pull requests, merge conflicts, and issue
management.

## Project Files

- `hello.py` - A simple Python program that prints a Hello World message.
- `apple.py` - A Python program that prints "I eat apple".
- `README.md` - Project documentation.

## Git and GitHub Features Demonstrated

- Created and configured a Git repository
- Made an initial commit
- Created and worked with branches
- Added a new feature
- Created and reviewed a pull request
- Merged a pull request
- Simulated a merge conflict
- Resolved a merge conflict
- Created and managed GitHub Issues

## Branches

### main
The main branch contains the completed project.

### feature-1
This branch was created to add the `apple.py` feature.

### conflict-branch
This branch was created to demonstrate a merge conflict by modifying
`hello.py`.

## Pull Request

A pull request was created to merge `feature-1` into `main`. The changes were
reviewed by a classmate before the pull request was merged.

## Merge Conflict

A merge conflict was intentionally created by modifying the same line in
`hello.py` differently on the `main` and `conflict-branch` branches.

The conflict was resolved manually by editing `hello.py`, removing the Git
conflict markers, and keeping the desired final version. The resolved file
was then committed and pushed to the `main` branch.

## GitHub Issues

### Issue #2 - Improve README documentation
The README documentation was improved by adding information about the project,
files, branches, GitHub features, and the merge conflict resolution process.
The issue was completed and closed.

### Issue #3 - Review project files
The project files were reviewed to verify that `hello.py` and `apple.py`
met the assignment requirements. The programs were confirmed to execute
correctly and produce the expected output. The issue was completed and closed.
